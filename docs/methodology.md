# Methodology

Rivermetry presents official river observations and, where explicitly matched, official NOAA/NWS forecasts. The service does not create flood-risk scores, safety recommendations, or proprietary forecasts. Current trend labels describe measured gage-height change only, using a 60-minute comparison window and a ±0.03 ft deadband. Every current value must retain its observation time; data older than 90 minutes are not presented as current.
